## About

VATS Global Logistics assists exporters, importers, freight forwarders and logistics companies in obtaining mandatory cargo documentation required by various African countries.

Our services include:

- ECTN
- CTN
- BESC
- BSC
- FERI
- BIETC
- CNCA
- Other African Cargo Certificates
